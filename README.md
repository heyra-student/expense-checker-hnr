# 경비 정산 검사기 (Expense Policy Auditor)

Next.js (App Router), TypeScript, Tailwind CSS 기반의 사내 경비 정산 규정 자동 검사 웹 애플리케이션입니다.  
월말 경비 정산 내역 CSV 파일을 업로드하면 브라우저 상에서 즉시 사내 경비 규정(제5조~제9조)을 검증하여 위반 항목을 검출하고, 제출자별 반려 사유를 원클릭으로 클립보드에 복사할 수 있습니다.

---

## 🚀 주요 기능

### 1. 클라이언트 사이드 CSV 파싱 및 반응형 테이블 뷰 (PRD 3.1)
* **Zero Persistence (보안 준수):** 외부 서버나 데이터베이스로 금융 내역을 전송하지 않고 순수 브라우저 메모리 상에서 PapaParse로 파싱 및 검증합니다.
* **실시간 데이터 그리드:** 12개 컬럼(번호, 제출자, 부서, 일시, 항목, 가맹점, 금액, 인원, 증빙, 품의번호, 제출일, 메모)을 반응형 테이블로 렌더링.
* **다중 필터 지원:** 부서별 필터 및 실시간 텍스트 검색(제출자, 가맹점, 사유 등) 기능 지원.

### 2. 룰 엔진 (Policy Rules Engine, PRD 3.2)
* **제5조 (식대):** 1인당 1회 12,000원 한도 초과 검출 (인원수별 1인당 금액 자동 계산).
* **제6조 (교통비):** 22:00 이전 퇴근 택시비 불인정 및 업무상 이동 목적 미기재 검출.
* **제7조 (증빙):** 30,000원 이상 지출 시 간이영수증 불인정 (적격증빙 필수).
* **제8조 (접대비):** 300,000원 초과 접대비 사전 품의번호 누락 검출.
* **제9조 (제출 - 기한):** 사용일로부터 30일 초과 제출 검출.
* **제9조 (제출 - 중복):** 동일 지출(사용일·가맹점·금액 일치) 중복 제출 검출 (1차 원본 외 후속 제출 건 위반 처리).
* **위반 건 하이라이트:** 위반된 행에 빨간색 배지/경고 스타일 적용 및 위반 조항과 구체적 사유 노출.

### 3. 대시보드 요약 (Summary Cards, PRD 3.3)
* **핵심 지표 카드:** 전체 검사 건수, 규정 위반 건수, 정상 처리 건수 및 비율 시각화.
* **조항별 위반 통계 칩:** 제5조~제9조 항목별 위반 건수 집계 칩 제공 (칩 클릭 시 해당 조항 즉시 필터링).

### 4. 필터링 및 원클릭 복사 (PRD 3.4)
* **"위반 건만 보기" 토글:** 원클릭으로 위반 행만 테이블에 즉시 필터링.
* **제출자별 반려 사유 클립보드 복사:** 제출자별 위반 내역을 자동 그룹화하여 메신저(카카오톡, Slack) 및 이메일에 바로 붙여넣을 수 있는 텍스트 자동 생성 및 복사.
* **전체 위반자 일괄 복사:** 전체 위반자 요약본을 한 번에 복사 지원.
* **미리보기 팝업 모달:** 복사 전 생성 문구 사전 확인 기능 제공.
